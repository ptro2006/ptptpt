<b>Wat is een source hosting platform en voor welke heb jij gekozen? </b> 
Een source hosting platform is een digitale plek om code op te slaan, ik heb gekozen voor GitHub.

<b>Welke domeinnaam heb je gekozen en hoe heb je die gekoppeld aan je pagina?</b> 
Ik heb voor de domeinnaam 'whatsyourpta' gekozen, dit omdat ik een vogel heb genaamd pietie (pt) en zij mijn hele wereld is. Of ik nou iets ga doen over haar voor de website of niet maakt niet uit, iedereen die mij goed kent, kent haar. En het whats your ..ta, komt van het liedje 'ETA' vna NewJeans, waar ze meerdere keren herhalen 'what's your ETA?'. Ik heb de domeinnaam gekoppeld door via TransIp bij DNS instellingen vier A-records te maken en dan nog mijn eigen domeinnaam als vijfde adres erbij toe te voegen. Vervolgens ben ik op Github naar pages gegaan en voerde ik bij *Custom Domain* "whatsyourpta.nl" in.

<b>Beschrijf hoe je aanpassingen aan jouw pagina kunt maken en hoe je er voor zorgt dat die op het web gepubliceerd worden.</b>
